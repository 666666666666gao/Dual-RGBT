# 本轮训练采样范围核对

本核对服务于完整训练的范围说明，不执行新的训练、图像读取或正式评价。
脚本为`scripts/audit_sampling_scope.py`；只用NumPy、当前manifest、已结束A/B/C的配置、
完成文件与CSV。独立源码审查单独记录，真实manifest重建结果将在运行后填写。

本轮执行器A由空间版短程A和扩大A构成：前者2轮×2000样本、batch4、1000更新，
后者实际epoch3–7共5轮×10000样本、batch8、新增6250/累计7250更新。
扩大B为5轮×10000样本、batch8、6250更新。
A/B按原`LasHeRPairs`每个样本独立seed重建序列与搜索帧选择，
各epoch seed为`2027+(epoch-1)*samples`，不是每轮重复相同随机种子。

A使用顺序DataLoader，drop_last=True；两种样本数都能被batch整除。
保存CSV的连续step及modality/action确定每个batch路径，
据此统计RGB/TIR×五动作的样本数量、涉及序列和唯一搜索帧。
B不会套用A的route分组；原B在每个样本上分别计算两主模态与各辅助动作以产生监督。

“序列参与采样”只表示该序列出现过，不能证明其全部帧都经过训练。
唯一搜索目标以`(sequence, frame)`计，不包含模板、连续裁剪坐标或像素数。
原sampler只从valid_frames的第3个及后续位置抽搜索帧，前两个有效帧不属于这个统计的分母。
同一帧可通过不同模板与随机裁剪形成不同训练样本，因此唯一帧数也不等于训练信息量。

C仍为固定20条完整序列两轮：17,708次track、40次初始化、3504次有效监督更新。
按原manifest计算其不同非初始化帧占全882条的比例，同时列出假设全882条两轮所需track次数；
后者只是计算量预算，不是已经启动或完成的训练，不改变当前完整dev/test的执行顺序。

这是从**当前manifest与固定源码**重建的输入索引。A/B没有逐样本图像加载日志，
本次manifest SHA只绑定本审计输入，不补造历史启动时的独立快照证明。
CSV与COMPLETE约束已完成的更新数、顺序及配置，不把源码重建等同于图像/张量逐位重放。
它不证明准确率、延迟、泛化、每条路径收敛或三个模块的独立贡献。
