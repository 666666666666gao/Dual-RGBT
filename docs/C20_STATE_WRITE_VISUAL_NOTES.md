# C20 错误写入的四个原图例子

这些是旧C20、cost0.05的dev轨迹例子，用于检查具体失败形态，不用于估计频率、比较算法或证明因果。32张原始RGB/TIR图像及GT/预测叠框仅在私有目录保存，不上传Git。原图逐文件SHA、传输exit码、GT序列化一致性与选择条件在私有provenance中保留。

选择规则固定为：唯一“错误写入前一帧IoU≥0.5”事件、按已保存序列顺序首次confidence≥0.95的错误写入、首次此前已连续低IoU至少20帧且目标中心在主crop内的事件，以及对应首次中心在crop外的事件。四个条件得到三个不同序列，其中两个例子来自同一序列，不能当作四个独立样本。

每例显示初始化帧、当前连续低IoU段之前一帧、写入事件帧及其后20帧。程序帧号从0开始；“连续低IoU段之前”不保证身份正确或IoU≥0.5。图中绿色是数据集GT、紫色是已保存预测。画面按两框并集放大，不改变原图内容；RGB和TIR均展示。

| 例子 | 序列／事件帧 | 执行者目视观察 |
|---|---|---|
| 前一帧IoU≥0.5 | folderatlefthand / 370 | 369帧预测跨越两个相近板状物，370帧偏向右侧物体，GT在左侧。后续左侧区域存在遮挡或外观变化；仅凭四帧不能排除标注边界变化，也不能证明当前写入导致切换。 |
| 高响应错误写入 | left2ndboy / 425 | 主模态为TIR，查询后的最终响应约0.952，并非独立TIR质量分数。预测落在红衣行人，GT在旁边黑衣行人；TIR中两人热轮廓相近。该例显示可辨认的热目标轮廓与最终高响应仍可伴随跟错对象，不能推广到所有TIR高响应。 |
| 目标中心仍在主crop内 | leftdrillmasterstanding / 655 | RGB中目标与邻近行人服装相近，所选框和GT落在不同人上，TIR中也有多个相近热轮廓。支持在该例检查身份关联，不能把所有内部错误都归为相似干扰物。 |
| 目标中心在主crop外 | leftdrillmasterstanding / 840 | GT目标仍在原图中，所选框停留在旁边队列位置。crop外判断来自六位小数保存框的几何重建近似；原图可见与当前局部搜索能读到是两个不同条件。 |

655和840帧的小目标若映射到当前E1的32×32全图预览网格，其宽度不足一格。这是对该几何配置的投影，C20本身没有运行E1全图预览；不能据此声称已经观察到E1失败，也不能把网格单元大小当作CNN不能辨别目标的硬界。它提出一个待验证的容量问题：身份排序之外，预览分辨率及候选分离距离是否限制密集小目标检索。

后续先完成已登记E0/E1。若其真实轨迹仍出现同类问题，在保留三模块职责的前提下，比较身份约束检索、普通时间关联、预览分辨率及候选分离参数；同时匹配候选数、辅助token预算并报告真实延迟。写入控制实验仍是判断模板因果作用的必要证据。
