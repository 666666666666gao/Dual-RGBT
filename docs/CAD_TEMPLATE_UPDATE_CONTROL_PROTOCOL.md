## 四个固定对照

| 模式 | 动态模板行为 | 门的分数和比较 |
|---|---|---|
| U0 `off` | 禁止动态写入，保留两个初始槽 | 不使用更新门 |
| U1 `legacy` | 原条件下写主模态，查询后才写辅助 | 原现有confidence，周期5、`>=.65` |
| U2 `cad_selected` | 保留U1模态写入规则 | E0及E1主路径复用已加窗分数；仅E1辅助query的更新门补对应8/16网格Hann，周期5、严格`>.65` |
| U3 `cad_pair` | 门接受后成对写RGB/TIR动态槽 | 与U2同门 |

固定同一完整checkpoint、cost、候选池、K、seed、模板数和全部网络参数；不得把无窗分数再用于U2门，也不得给已有窗的E0/E1主分数重复乘窗。query的门窗不得改变本帧box readout。slot0不可改写。此为CADTrack-style适配，不是完整CADTrack轨迹复现。Hann可能压低偏心真目标的更新机会，成对写入可能保留差模态；不预定U3最佳或预计涨幅。

门窗采用仓库 `lib/test/utils/hann.py` 的 `hann2d(centered=True)`，保存并检查实际8×8/16×16窗定义与dtype。
